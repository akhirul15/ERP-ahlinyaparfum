# AhlinyaParfum ERP — POS Kasir UI Prototype

File:
- index.html
- styles.css
- app.js
- products.js

Cara menjalankan:
1. Letakkan semua file dalam folder yang sama.
2. Buka index.html di browser.
3. UI memakai data master produk dari workbook yang diunggah (587 produk).
4. Fitur saat ini bersifat frontend prototype: pencarian, kategori, varian, volume, botol, konsentrasi, grade, keranjang, member/poin, checkout, cetak resi, resi digital, WhatsApp dan email.
5. WhatsApp/email masih memakai browser (wa.me dan mailto). Pada tahap backend nanti, ini diganti API agar pengiriman tercatat di ERP.

Catatan:
- Harga varian pada prototype dihitung dari harga dasar Excel menggunakan faktor simulasi. Ini BUKAN harga final database.
- Nama produk dan harga dasar berasal dari sheet Produk pada workbook yang diunggah.
- Backend dan database belum terhubung.
